# Applying-XAI-for-Demand-Forecasting-and-Pricing-Decision-in-Supply-Chain
Demand forecasting, explainable AI (SHAP, LIME, PDP), and price optimization using machine learning and deep learning models.
This Source Code for the implementation of the capstone project for Master's Degree contains the following:

*   Data Import and Exploration
*   Data Merging and Visualization
*   Statistical Hypothesis Testing   
*   Sampling
*   Feature Engineering

Full code will be devided on 4 files as following:
1. Capstone Project_Data_Processing
2. CapstoneProject_CatBoost_SHAP_PDP_LIME_Price_Optimization
3. Capstone Project_LSTM_Model
4. Capstone Project_TCN_Model

Data Set used in this project :
1. Walmart M5Kaggle link here(https://www.kaggle.com/competitions/m5-forecasting-accuracy)
2. Macroeconomic Indicators from US Government website gathered on the same time period of walmart data.
